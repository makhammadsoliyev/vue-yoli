# Mashg'ulotlar kundaligi

Yangi yozuv har doim **tepaga** qo'shiladi. Bir mashg'ulot = bitta yozuv, 5–8 qator.

## Shablon

```markdown
## YYYY-MM-DD · N-kun · mavzu

- **Vaqt:** 2 soat (kompyuter: uy / ish)
- **Qilindi:** qaysi mashqlar (t1–t4), qaysi commit'lar
- **Qiyin bo'ldi:** nima tushunarsiz yoki uzoq vaqt oldi
- **Tushundim:** bir-ikki jumla bilan asosiy xulosa
- **Quiz:** 0/0
- **Keyingi safar:** nimadan boshlash
```
